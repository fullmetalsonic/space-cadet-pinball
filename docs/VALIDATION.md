# Space Cadet Pinball 검증 현황

**기준:** v1.2 · 2026-10-15

## 판정 요약

| 요구사항 묶음 | 개수 | 결과 |
|---|---:|---|
| 활성 요구사항 | 21 | PASS 20개, 부분 검증 1개 |
| 제거된 동작 센서 요구사항 | 5 | N/A, 통과 수에서 제외 |

제품 전체는 아직 완료 상태가 아닙니다. **AUDIO-01은 부분 검증**입니다. 휴대폰에서 최종적으로 소리가 들리는지 확인하지 않았습니다. 오디오 데이터 생성이나 에뮬레이터의 재생 시작만으로는 플레이어가 듣는 결과를 확정할 수 없습니다.

## 확인 범위

- **Windows:** 휴대용 빌드 실행, 주요 게임·입력 흐름, 로컬 점수와 설정 저장, 새 프로세스에서의 저장값 확인, 저장소 복구를 제한된 실행에서 확인했습니다.
- **웹:** 대표적인 게임 흐름, 터치 해제·취소, 로컬 저장, 오프라인·업데이트 동작과 관련 브라우저 흐름을 확인했습니다. 코드 경로가 바뀌지 않은 부분은 기존 증거를 재사용했습니다.
- **Android:** 멀티터치, 입력 취소, 일시정지·재개, 패키지 서명과 네이티브 라이브러리 정렬을 확인했습니다. 16KB 런타임 결과는 ARM 변환을 사용하는 에뮬레이터에서 얻었으며, 실기기 결과가 아닙니다.
- **공통 게임 동작:** v1.2 요구사항에 따라 대표적인 게임·규칙·점수·너지·화면 배치·언어·도움말·저장 경로를 확인했습니다. 원본 Tilt 제재는 유지되며 휴대폰 동작 센서 기능은 제거되었습니다.

## 판정 해석과 한계

PASS는 시험한 경로에서 요구 결과를 확인했거나, 변경 영향이 없는 경로에 적절한 기존 증거를 적용했다는 뜻입니다. 모든 기기·화면 크기·게임 상황·과거 버전·시뮬레이션 프레임을 시험했다는 뜻은 아닙니다. N/A는 범위에서 제거된 기능을 나타내며 통과로 계산하지 않습니다. 부분 검증은 필수 결과가 아직 확인되지 않은 항목입니다.

센서 관련 5개 요구사항은 휴대폰 센서 기능과 센서 설정·보정·민감도·도움말이 제거되어 N/A입니다. 화면 너지 버튼과 게임 원본 Tilt 제재는 검증 범위에 남아 있습니다.
