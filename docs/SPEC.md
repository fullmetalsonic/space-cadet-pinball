# Space Cadet Pinball 사양

## 제품 개요

Space Cadet Pinball은 Windows, 웹 브라우저, Android에서 플레이할 수 있는 핀볼 게임입니다. 공통 게임 동작을 유지하면서 각 플랫폼의 키보드·터치 조작과 배포 방식에 맞춰 제공합니다.

## 플레이 및 플랫폼 범위

- 1~4인 게임을 시작하고, 공을 발사해 플리퍼와 너지를 조작하며, 일시정지·재개와 게임 종료까지 진행합니다. 점수와 플레이어 차례는 게임 흐름에 맞게 표시합니다.
- 데스크톱에서는 키보드 조작과 키 재지정을, 웹과 Android에서는 터치 조작을 제공합니다. Android에서는 여러 터치 입력을 함께 처리하고 일반적인 일시정지·재개 흐름을 지원합니다.
- 좌·우·앞 방향의 화면 버튼 너지를 제공합니다. 게임 원본의 Tilt 제재도 유지합니다.
- 한국어와 영어 메뉴·도움말을 제공하고, 플레이어 이름·최고점·설정을 로컬에 저장합니다. 이름 입력을 취소하면 기록을 추가하지 않습니다. 다시 실행할 때는 새 게임을 시작하며, 끝나지 않은 게임을 복원한다고 표시하지 않습니다.
- 웹은 최초 접속 후 오프라인으로 실행할 수 있고, 대표적인 앱 업데이트 뒤에도 저장된 점수와 설정을 유지합니다.
- Windows 휴대용 빌드와 Android ARM64 패키지를 제공합니다.

## Android 동작 센서 범위

휴대폰 동작 센서 기능은 현재 제품 범위에서 제외되어 있습니다. 센서 기반 너지, 센서 설정·보정·민감도 조절과 센서 안내를 제공하지 않습니다. 화면 너지 버튼과 게임 원본 Tilt 제재는 계속 제공됩니다.

## 완료 기준

현재 활성 요구사항은 21개이며, 그중 20개는 PASS이고 AUDIO-01은 부분 검증 상태입니다. 센서 관련 5개 항목은 N/A이며 활성 통과 수에서 제외됩니다. 따라서 제품 전체 완료로 판정하지 않습니다. 완료에는 적용 플랫폼의 활성 사용자 흐름과 알려진 중대 결함의 해결이 필요합니다. 빌드 결과만으로 플랫폼 동작을 추정하지 않으며, 확인하지 않은 기기·브라우저 동작은 미검증으로 남깁니다.
